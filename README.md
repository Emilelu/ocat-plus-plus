# OCAT++

> OCAT 收藏夹增强工具 — 纯浏览器端运行，支持从手机一键同步数据库。

基于 SQL.js 在浏览器中直接读取 SQLite 数据库，无需安装任何后端服务。界面采用 Material Design 3，支持深浅色模式。

## 快速开始

1. 双击 `index.html` 打开页面
2. 点击「选择数据库」加载 SQLite DB 文件
3. 开始浏览、搜索、导出

> 首次加载后数据会自动缓存到浏览器，下次打开秒开。

## 手机同步

需要先开启手机 USB 调试（仅首次设置），然后启动同步服务。

### 首次设置：开启 USB 调试

1. 手机「设置」→「关于手机」→ 连续点击「版本号」7 次
2. 「设置」→「开发者选项」→ 开启「USB 调试」
3. 用数据线连接电脑，手机上点击「允许」

### 启动同步服务

```bash
cmd /c "cd /d <项目目录> && python sync_server.py"
```

保持窗口运行，在浏览器中点击「📱 同步手机」即可。支持三种同步方式：

| 方式 | 适用条件 |
|---|---|
| 直接 pull | 有 Root |
| run-as | Debuggable 应用 |
| adb backup | 通用（需在手机上确认） |

## 功能

| 功能 | 说明 |
|---|---|
| 收藏夹浏览 | 左侧导航栏，按语言分类，可拖拽调整宽度 |
| 分栏折叠 | 有分栏的收藏夹默认展开第一个，其余折叠 |
| 分栏快速跳转 | 顶部导航标签，点击即时定位 |
| 全文搜索 | 跨收藏夹搜索，按句子/翻译/提问/AI回答筛选 |
| 分页浏览 | 可调整每页数量，支持页码跳转和省略号 |
| 对话原文 | 弹窗查看完整 AI 回复，支持 Markdown 渲染 |
| 注音显示 | 日语句子假名注音显示在汉字上方 |
| 批量导出 | 勾选后导出 Anki CSV / CSV / TXT，级联勾选 |
| 单词查询 | 点击 📖 弹窗分词，联动 Jisho / OJAD / NHK |
| 划选查词 | 划选句子文字弹出快捷词典链接 |
| 语音朗读 | 基于 Web Speech API，支持日语/英语/中文 |
| 列表播放 | 列表循环、随机播放，播放中点击句子切换 |
| 音色切换 | 可选系统已安装的语音，自动匹配句子语言 |
| 倍速调节 | 0.5x ~ 2.0x，默认 1.25x |
| 自动滚动 | 播放中自动滚动到当前句子并高亮 |
| 自动展开 | 播放到折叠对话时自动展开 |
| 深浅色模式 | 跟随系统自动切换，也可手动切换 |
| 数据缓存 | 浏览器 IndexedDB 缓存，刷新秒开 |

## 技术栈

- **SQL.js** — 浏览器端 SQLite 引擎
- **Kuromoji.js** — 日语形态素解析（分词 + 词形还原）
- **TinySegmenter** — 日语分词（降级方案）
- **marked.js** — Markdown 渲染
- **Web Speech API** — 语音合成
- **Material Design 3** — 界面设计语言

## 常见问题

**Q: 同步提示「未检测到手机连接」？**

A: 检查 USB 调试是否开启、数据线是否支持数据传输、手机上是否已授权。

**Q: 手机没有 Root 能用吗？**

A: 可以，会自动走 adb backup 方式，需在手机上点一次确认。

**Q: 需要安装 Python 吗？**

A: 仅手机同步功能需要。从 https://python.org 下载安装。

**Q: 搜索会慢吗？**

A: 不会。数据在浏览器内存中，毫秒级本地搜索。

**Q: 怎么更新数据？**

A: 点击「📱 同步手机」一键拉取，或手动选择新的数据库文件。

**Q: 语音朗读没有声音？**

A: 检查浏览器是否支持 Web Speech API（Chrome/Edge 均支持），系统音量是否开启。
